### Features

- **pick:** pick one worktree by default, --multi for several

### Bug Fixes

- **status:** branches without commits no longer show as merged
- safer deletes and inspection, from a code review

### Performance

- **scan:** show worktrees as soon as they are found

### Internal improvements

- AGENTS.md for every coding agent, CLAUDE.md links to it
- CLAUDE.md, staticcheck in make check, a test for the package layering
- make-driven releases, pre-push tests, no binaries
- **releasing:** the repos exist; just clone the tap
- **readme:** installing from a clone
- Homebrew formula built from source
